# Stromkreis-Simulator

Stromkreise aus Quelle, Lampe, Motor, Schalter und Messgeräten zusammenstecken und messen.

Live: https://erikdahlmann.github.io/dm-stromkreise/
Früher auf Netlify: https://dm-stromkreise.netlify.app/ (online seit 2026-05-03). Erstellt mit Gemini 3 Pro.

Beim Umzug von Netlify entfernt: die Hilfsskripte, die Gemini Canvas beim Export einbaut (Firebase-Zugang, Abfangen von Netzanfragen mit API-Schlüssel). Die Seite braucht sie nicht.
